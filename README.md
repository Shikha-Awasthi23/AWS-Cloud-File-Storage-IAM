# Cloud File Storage Using AWS S3 and IAM

## Project Overview
This project demonstrates cloud-based file storage using Amazon S3 and access management using AWS IAM. S3 versioning was enabled to maintain previous versions of objects and support recovery from accidental overwrites or deletions.

## AWS Services Used
- Amazon S3
- AWS IAM

## Key Features
- Cloud-based object storage
- IAM-based access control
- S3 bucket versioning
- Improved data management and recovery

## Implementation
1. Created an Amazon S3 bucket.
2. Configured an IAM user and access policy.
3. Enabled versioning on the S3 bucket.
4. Verified the storage configuration.

## Security Considerations
- Follow least-privilege access.
- Keep S3 Block Public Access enabled unless public access is explicitly required.
- Never upload AWS access keys, secret keys, or sensitive files to GitHub.
